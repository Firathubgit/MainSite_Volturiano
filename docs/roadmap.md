Phase 0 — Foundations
- Initialize React/Vite app, CSS Modules + PostCSS, i18next, Zustand.
- Supabase project, schema + RLS, Storage buckets, Edge Functions boilerplate.
- 2D viewer MVP with one model, few colors; image prefetch on-hover.

Phase 1 — Configurator MVP
- Option groups UI; price calculation; save/share (config_code).
- Auth + personal garage; investor micro-site link.
- Performance budgets and A11y pass.

Phase 2 — 3D Mode & World
- Add optional R3F 3D viewer; HDRI environments; detail camera presets.
- VOLTURIANO WORLD subsection with connectivity/ownership UI.

Phase 3 — Payments & Admin
- Stripe deposit flow via Edge + webhooks; orders table.
- Admin-only content tools (add models/options/assets manifests).

Phase 4 — Interior, Sound, AR (exploratory)
- Interior panorama/3D, sound design, AR handoff (QR to mobile).
