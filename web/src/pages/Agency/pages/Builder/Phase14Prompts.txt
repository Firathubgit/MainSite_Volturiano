**Target:** API Developer
**Goal:** Create the core API route that handles repository creation and file pushing.

```markdown

This route must perform the following steps:

1. **Auth Check:** Verify the user is logged in (using the existing supabase auth middleware).
2. **Retrieve Files:** Use `sandboxManager` or fetch snapshots to get the current state of files for the requested `buildId`.
3. **Retrieve Token:** Fetch the `github_access_token` from the `profiles` table for the current user and decrypt it using our `github-crypto.js` utility.

   - Check if a repo with the specified name (or a default generated from the project name) exists.
   - If not, create a new private repository.
   - Use the GitHub "Trees" and "Commits" API through Octokit to perform a "blind push" of all files (index.html, src/, etc.) in a single commit.
   - Add a default `README.md` and `.gitignore`.
5. **Update Project:** If successful, save the repository URL back to the `projects` table in Supabase.
6. **Response:** Return the new repo URL and success status.

Reference `web/server/routes/publish.js` for how sandbox files are accessed and how Supabase is queried.
Please write the complete code for `web/server/routes/github-push.js` and show how to mount it in `server/index.js`.
```
