title: Internationalization Policy
description: Multi-language foundation and scaling rules.
status: active
apply_to: repo
labels: [i18n, localization]
---

Framework
- i18next with react-i18next. Namespaces per feature (e.g., common, nav, configurator, account, world).
- Default locale: en. Fallbacks: en -> provided language order.

File Structure (planned)
- /web/src/i18n/{en,sv,de,...}/{namespace}.json
- Keep translations flat and descriptive. No UI copy in code.

Runtime
- Detect via navigator.language and persisted user preference.
- Lazy-load namespaces on route entry; preload common + current route.

Content Hygiene
- No concatenated sentences; use interpolation and plurals.
- Screenshots in PRs when adding/changing strings.

Context
- i18next chosen for mature pluralization and interpolation. All copy lives in JSON to enable non-developer edits and future translation workflows without code changes.
