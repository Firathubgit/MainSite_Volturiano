# Manual Review Packet

Codex can draft and wire the flows, but this packet is for human confirmation before a public MVP.

## Lawyer/privacy review
- Terms of Service v2.
- Privacy Policy v2.
- Acceptable Use Policy.
- Data Processing Addendum.
- Subprocessor register.
- Takedown and moderation process.
- Refund policy.
- Customer responsibility guide.
- Incident response flow and 72h privacy escalation path.

## Accountant/bookkeeping review
- Stripe payout export.
- Stripe balance transaction report.
- Revolut/business account statement.
- Credit transaction ledger export.
- Refund/dispute reversal rows.
- Monthly reconciliation routine in `docs/finance/bookkeeping-workflow.md`.
- Storage location and retention for accounting evidence.

## Founder sign-off
- Decide whether MVP is B2B-only or allows consumers.
- Decide refund rules for used credits, unused credits and subscriptions.
- Decide retention windows for agent logs, snapshots, audit logs and community submissions.
- Decide when community auto-render can be enabled, if ever.

## Output
- Record review date.
- Record reviewer/person consulted.
- Record unresolved risks.
- Record final launch decision.
