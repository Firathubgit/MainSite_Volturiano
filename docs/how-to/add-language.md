---
title: How to Add a Language
description: Add a new locale to the site.
status: reference
---

Steps
- Create /web/src/i18n/<locale>/ with common.json, nav.json, models.json, configurator.json.
- Register the locale in i18n init and language switcher.
- Add any new rule messages or model names.
- Run through key flows and screenshot for PR.
